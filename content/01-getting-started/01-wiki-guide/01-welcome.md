# Welcome

This wiki is a set of Markdown files in the `content/` folder. There is no database and
no editor to log in to: you edit files, refresh the browser, and the change is there.

## How content is organised

| Level | What it is | On disk |
|-------|------------|---------|
| **Shelf** | A collection of related books | A folder in `content/` |
| **Book** | One topic, project or manual | A folder inside a shelf |
| **Chapter** | An optional group of pages | A folder inside a book |
| **Page** | The actual text | A `.md` file in a book or chapter |
